# サンタからの きんきゅうミッション

クリスマス会用の謎解きPWA（Android Chrome・横向き・全画面）。ビルド不要の HTML / CSS / JS です。

## 全体の流れ

```
📦 箱（スマホ＋手紙）→ アイコンを探して起動          ┐
📩 着信 → サンタの手紙                              │ スマホで
🔑 カギ①：数字さがし（5人で1けたずつ）               │
🔑 カギ②：小人の積木 → カメラでスキャン               ┘
📞 サンタからビデオ電話 →「テレビに ワープするぞ！」   ← ここでテレビにつなぐ
🔑 カギ③：まねまねポーズでクリスマスケーキ作り        ┐ テレビで
🎉 おいわい：ジングルベルを みんなで歌う              │
🎁 エンディング：最後のプレゼントのヒント             ┘
```

## あとで入れるもの

| 内容 | 場所 |
|---|---|
| パスコード・隠し場所ヒント・追加ヒント | `config.js` の `key1` |
| 大きい箱の場所ヒント | `config.js` の `key2.boxHint` |
| 最終プレゼントのヒント | `config.js` の `ending.finalHint` |
| 子ども5人の名前 | 管理画面「1. なまえ設定」（スマホの中だけに保存） |
| つみきの完成図 | 管理画面「5. 完成図エディタ」 |
| おいわいの歌の音源（任意） | 管理画面「6. おいわいの うた」。入れなければアプリのジングルベル |
| テレビのズレ調整 | 管理画面「7. テレビの ズレ調整」 |
| まねまねポーズの譜面・せりふ・速さ | `config.js` の `poseGame` |

## 隠し操作（パパ用）

- **管理画面**：左上の 🎄 を3秒長押し → 暗証番号（`config.js` の `adminPin`、初期値 `4071`）
- **早送り／強制クリア**：左上の 🎄 と右下の角を、2本指で同時に2秒長押し
  - まねまねポーズ中は、ゲームを飛ばしてケーキ完成の場面へ進みます

## 公開・更新（GitHub Pages）

1. このフォルダの中身を、リポジトリの一番上に置いてアップロード（Add file → Upload files → Commit changes）
2. 初回だけ：Settings → Pages → Branch を `main` / `(root)` にする
3. Android Chromeで開き、「ホーム画面に追加」→「インストール」

**変更したとき**は `sw.js` の `CACHE_VERSION` を1つ上げてからアップロードし、スマホでアプリを「履歴画面から上にスワイプして完全に閉じる → 開く」を2回やると新しい版に入れかわります。
※ 横向き・全画面の設定を変えたときは、ホーム画面のアイコンを一度削除して追加し直してください。

### ワープのときの手順（Googleホームで無線ミラーリング）
画面に「📺 テレビに ワープ！」が出たら、アプリは待機します。ゆっくりで大丈夫です。

1. 子どもにテレビの電源を入れてもらう（入力は前もってキャストの入力にしてある）
2. パパがスマホで **Googleホームアプリ** を開く
3. テレビ（または Chromecast）を選ぶ →「**画面をキャスト**」→「**画面のキャスト**」
4. 「キャストを開始しますか？」と出たら「**今すぐ開始**」
5. テレビにスマホの画面が映ったら、アプリに戻って子どもに「**✨ ワープ！**」を押してもらう

- 手順の名前は、スマホやアプリの版で少し違うことがあります（クイック設定の「画面のキャスト」からでもつなげます）
- つないだあとは、最後までそのままにしておいてください（おいわいの歌とエンディングもテレビで見ます）

## まねまねポーズの譜面の書き方

`config.js` の `poseGame.sets` に、前半・後半の2セットがあります。1行が1フレーズ（サンタが おどる → サンタと いっしょに）です。

```js
{ who: "all", hits: [[1, "flamingo"], [3, "banzai"]] }
```

- `hits`：`[拍, ポーズ]`。拍は1〜4（`bars: 2` なら1〜8）。ポーズは2拍以上あけると真似しやすい
- `tame: true`：「ためて〜…」の表示が出る
- ポーズ：`banzai`🙌 `hoshi`⭐ `flamingo`🦩 `disco`🕺 `robot`🤖 `hohoho`😆 `yukidaruma`☃️ `tonakai`🦌
- `bpm` を上げると速くなります
